# Aegis Spendly — Prepopulated Demo Version

This folder contains the **dedicated demo version** of Aegis Spendly with prepopulated demo fields:
- **3 Bank Accounts**: ICICI Bank (₹82,500), Axis Bank (₹42,600), HDFC Bank (₹18,300)
- **3 Credit Cards**: HDFC Regalia (₹3,00,000 limit), Axis Ace (₹1,50,000 limit), ICICI Coral (₹1,00,000 limit)
- **Prepopulated Transactions**: Groceries, Salary, Dining, Utilities, Investments, Shopping
- **Prepopulated Obligations**: Rent, Car EMI, Health Insurance
- **Prepopulated SIP Investments**: Nifty 50 Index Fund, Parag Parikh Flexi Cap Fund
- **Prepopulated Debts & Receivables**: Amit Loan, Rahul Borrowing

## Quick Start
To run this standalone demo version:
```bash
npm install
npm run web
```
This version bypasses empty-vault state and always displays full, rich interactive financial metrics for demonstration and testing purposes.
