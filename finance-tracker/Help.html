❓ Help & Documentation

Getting Started

Use the 💰 Finance Tracker menu at the top of your spreadsheet to access all features.

🏗️ Initialize All Sheets
Run this once to create all required sheets and default master data.

Adding Transactions

Click ➕ New Transaction to open the sidebar form. Switch between Income and Expense tabs. All fields with * are required.

  • Transactions get a unique auto-generated ID
  • Running balance updates automatically
  • Recent transactions appear at the bottom of the form

Transfers

Use 🔄 Transfer Between Accounts to move money between accounts. This creates two ledger entries (debit + credit) to keep balances accurate.

Master Data

Manage categories, payment modes, accounts, and vendors through ⚙️ Setup → Manage Master Data. Changes reflect in form dropdowns immediately.

💡 To deactivate an item without deleting it, go to the master sheet directly and change "Yes" to "No" in the Active column.

Budgets

Set monthly spending limits by category via ⚙️ Setup → Set Monthly Budgets. Then generate a "Budget vs Actual" report to track how you're doing.

Dashboard

Click 📊 Refresh Dashboard to update your financial dashboard with:

  • Current balance, total income & expenses
  • This month's breakdown
  • Category-wise expense distribution (with pie chart)
  • Monthly trend (with bar chart)
  • Recent transactions

Reports

Generate reports via 📋 Generate Monthly Report:

  • Monthly Statement — full month summary + all transactions
  • Yearly Statement — annual overview
  • Category-wise — spending by category with percentages
  • Cash Flow — 12-month income/expense/net/cumulative view
  • Account-wise — per-account inflows, outflows, and net
  • Budget vs Actual — compare planned vs actual spending

Sheets Overview

Ledger — All transactions in chronological order
Dashboard — Visual summary and KPIs
Reports — Generated reports land here
Budgets — Monthly budget targets
Transfers — Account-to-account transfers log
AuditLog — Every action is tracked here
M_* — Master data sheets (categories, accounts, etc.)
Settings — Currency, date format, last TxnID

Tips

💡 Use Tags and Projects on transactions to group spending across categories (e.g. tag a trip's food, hotel, and transport together).
💡 Mark transactions as Recurring to flag regular payments for future reference.
💡 To change your currency symbol, edit the Settings sheet: find the "Currency" row and change the value.

Architecture

This system follows a modular design with separation between data entry (sidebar forms), storage (Ledger + master sheets), presentation (Dashboard), and analysis (Reports). The audit log tracks all actions for accountability.
